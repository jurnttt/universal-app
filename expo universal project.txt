- Code Repository: Git initialized and pushed up to my GitHub profile.
- Folder Architecture: Using the professional, production-grade Feature-Driven layout (src/app/ for routing, src/features/ for domain blocks, and src/shared/ for configuration data and global elements).


This is the professional file architecture for an Expo universal, cross-platform app (Web, iOS, Android) that handles your portfolio layouts cleanly. This setup uses Expo Router (the industry standard for folder-based navigation). A single layout design file maps automatically to a mobile application view or a web browser URL.

src/
├── app/                        # EXPO ROUTER PATHS & NATIVEWIND ROOT
│   ├── _layout.tsx             # Global layout: Configures NativeWind, Safe Area, & Status Bar
│   ├── index.tsx               # App Home screen (Maps to "/")
│   ├── profile.tsx             # Profile screen (Maps to "/profile")
│   └── (auth)/                 # URL-invisible group for clean route separation
│       ├── _layout.tsx         # Auth layout (stack navigation)
│       └── login.tsx           # Login screen (Maps to "/login")
│
├── features/                   # BUSINESS DOMAINS (SELF-CONTAINED)
│   ├── auth/                   # Authentication Domain
│   │   ├── api/                # Auth-specific network requests/services
│   │   ├── components/         # Domain-specific components (e.g., LoginForm.tsx)
│   │   ├── hooks/              # Custom hooks for auth logic (e.g., useAuthMutation.ts)
│   │   └── types.ts            # Local TypeScript types for auth
│   └── user-profile/           # Profile Management Domain
│       ├── components/         # AvatarImage.tsx, ProfileForm.tsx
│       └── hooks/              # useFetchProfile.ts
│
└── shared/                     # THE PROJECT FOUNDATION (DOMAIN-AGNOSTIC)
    ├── assets/                 # App assets compiled by Metro (images, icons, fonts)
    ├── components/             # Reusable atomic UI (Button.tsx, Input.tsx, Card.tsx)
    ├── hooks/                  # Global helper hooks (useDebounce.ts, useIsOnline.ts)
    ├── styles/                 # Global styles or configuration helper files
    │   └── global.css          # Core entry file for NativeWind tailwind directives
    └── utils/                  # Standalone functions (formatDate.ts, validators.ts)
